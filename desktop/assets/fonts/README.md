# Noto Sans SC

`NotoSansSC.ttf` is the Noto Sans SC variable font from the Google Fonts
repository at commit `2894aab31764f10f29c421bdfd2340d3b382d384`.
It is included as a fallback so Chinese UI text remains readable on Linux
systems without a CJK font. The font is distributed under `OFL.txt`.

Source: https://github.com/google/fonts/tree/2894aab31764f10f29c421bdfd2340d3b382d384/ofl/notosanssc
